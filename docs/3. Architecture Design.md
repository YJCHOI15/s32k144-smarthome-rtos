# Architecture Design

## 1. 아키텍처 개요

- RTOS 기반 계층 구조
    - Input Layer (Event  Data Source): 버튼, 센서, CAN 인터럽트
    - Communication Layer (Message Hub): Queue, Mutex, EventGroup
    - Control Layer (Decision): MainControlTask
    - Output Layer (Action): Actuator, Display

### 2.2. Task

| Task | 역할 |
| --- | --- |
| **MainControlTask** | 시스템 모드/상태 관리, Command/Sensor 데이터 처리, 보안 이벤트 처리 |
| **SensorTask** | 온습도/조도/VR 센서 주기 수집 (1000ms) |
| **ButtonInputTask** | 버튼 ISR → 세마포어 → 명령 생성 후 Command Queue에 전달 |
| **CANCommTask** | CAN 수신 인터럽트 처리(명령 큐 전달), 주기적 송신(2000ms) |
| **SecurityEventTask** | 초음파 센서 기반 보안 이벤트 감지 (200ms), EventGroup에 이벤트 비트 세트 |
| **DisplayTask** | OLED/FND 갱신 (1s 주기) |
| **FNDScanTask** | 2ms 주기로 FND 멀티플렉싱 스캔 |

### 2.3. 데이터 교환 객체

| 객체 | 역할 | producter → consumer |
| --- | --- | --- |
| **g_command_queue** | 버튼/원격(CAN) 명령 전달 | ButtonInputTask, CANCommTask → MainControlTask |
| **g_sensor_data_queue** | 센서 데이터 전달 | SensorTask → MainControlTask |
| **g_system_status_mutex** | 시스템 상태 보호 | MainControlTask, CANCommTask, SecurityEventTask |
| **g_display_data_mutex** | 디스플레이 데이터 보호 | MainControlTask → DisplayTask, FNDScanTask |
| **g_button_interrupt_semaphore** | 버튼 ISR → ButtonInputTask 깨움 | PORTE_IRQHandler → ButtonInputTask |
| **g_uwave_interrupt_semaphore** | 초음파 Echo ISR → SecurityEventTask 깨움 | PORTC_IRQHandler → SecurityEventTask |
| **g_security_event_group** | 보안 이벤트 비트 관리 | SecurityEventTask → MainControlTask |
