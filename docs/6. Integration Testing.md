# Integration Testing

모듈 간 연동이 올바른지 검증한다. 

각 개별 모듈이 RTOS 태스크 + 큐/세마포어/이벤트 그룹을 통해 제대로 협력하는지 확인한다. 

| 시나리오 | 관련 모듈/태스크 | 테스트 항목 | S/F |
| --- | --- | --- | --- |
| **버튼 입력 → 장치 제어** | `ButtonInputTask` → `MainControlTask` → `Actuator` | 버튼1: 모드 전환 / 버튼2: 장치 선택 / 버튼3,4: 액션 | S |
| **센서 값 → 자동 제어** | `SensorTask` → `MainControlTask` → `Fan`, `MainLight` | 온도 높음 → 팬 ON / 조도 낮음 → LED 밝기 증가 | S |
| **보안 이벤트 → 알람** | `SecurityEventTask` → `MainControlTask` → `Sound`, `LED` | 초음파 거리 감지 < Threshold | S |
| **상태 표시 (Display)** | `MainControlTask` → `DisplayTask` & `FNDScanTask` | 모드/센서값 갱신 시 표시 업데이트 | S |
| **CAN 통신 연동** | `CanCommTask` ↔ `MainControlTask` | PC에서 CAN 명령 수신 → Command Queue 전달 | S |
| **UART 로깅** | 모든 Task → `SHH_Uart_Printf()` | 동시에 여러 Task에서 로그 출력 | S |

- **데이터 큐 통신 실패 및 FND 멈춤 현상**
    
    → UART 로깅(Task) + FND 출력(Task) 통합 시 문제 발생
    
    → 기록: *"snprintf → 스택 오버플로우, 불필요한 큐 의존 → 전역변수+Mutex 전환으로 해결"*
    
- **CAN 통신 송수신 (MCU ↔ PC)**
    
    → FlexCAN 드라이버 + 상위 애플리케이션 통합 확인
    
    → 기록: *"CAN Tx/Rx 정상, 로직애널라이저로 신호 확인 완료"*
