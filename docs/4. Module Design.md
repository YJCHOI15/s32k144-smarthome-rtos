# Module Design

## 1. 모듈 구조

시스템의 안정성과 재사용성을 높이기 위해, 소프트웨어는 다음과 같이 4개의 Layer으로 구분된 모듈로 구성된다.

<img width="1096" height="756" alt="image" src="https://github.com/user-attachments/assets/cb4a00b3-8472-4fe5-bbd8-f6aeff066992" />

### 1.1. Driver Layer (`drivers/`)

- MCU의 Peripheral을 직접 제어하는 저수준 함수를 제공
- 레지스터 접근, 입터럽트 처리, 클럭 설정 등 하드웨어 종속적인 기능 포함

### 1.2. Middleware Layer (`sh_config.h`)

- RTOS 객체(Queue, Semaphore, EventGroup 등)를 정의 및 관리
- 시스템 전역에서 공유하는 데이터 구조(`system_status_t`, `sensor_data_t`, `display_data_t`) 관리
    
    ```c
    /* 시스템 모드를 나타내는 열거형 */
    typedef enum {
        MODE_MONITORING,
        MODE_MANUAL,
        MODE_SECURITY
    } system_mode_t;
    
    /* Command Queue를 통해 전달될 명령 ID */
    typedef enum {
        CMD_NULL = 0,
        /* 버튼 입력 명령 */
        CMD_BTN1_CYCLE_MODE,
        CMD_BTN2_SELECT_DEVICE,
        CMD_BTN3_DEVICE_ACTION_POSITIVE,
        CMD_BTN4_DEVICE_ACTION_NEGATIVE,
        /* CAN 원격 명령 */
        CMD_CAN_SET_MODE = 0x20,
        CMD_CAN_ALARM_OFF = 0x21,
        CMD_CAN_CONTROL_DEVICE = 0x22
    } command_id_t;
    
    /* Command Queue를 통해 전달될 메시지 구조체 */
    typedef struct {
        command_id_t command_id; 
        int32_t value;      
            /**
             * CMD_CAN_SET_MODE:
             * 0: MODE_MONITORING, 1: MODE_MANUAL, 2: MODE_SECURITY
             */
            /**
             * CMD_CAN_CONTROL_DEVICE:
             * 하위 8비트 (0-7): 제어할 장치 ID (1=서보, 2=스텝, 3=릴레이)
             * 상위 24비트 (8-31): 동작 값 (0=OFF/닫힘, 1=ON/열림, 스텝 모터의 경우 이동할 스텝 수)
             */
    } command_msg_t;
    
    /* Sensor Data Queue를 통해 전달될 메시지 구조체 */
    #define TEMP_THRESHOLD   27  // FAN 작동 온도
    typedef struct {
        uint8_t temperature;
        uint8_t humidity;
        uint16_t cds_raw; // 0-4095
        uint16_t vr_raw;  // 0-4095
    } sensor_data_t;
    
    /* 초음파 감지 거리 */
    #define SECURITY_DISTANCE_THRESHOLD_CM 30
    
    /* Display Data Queue를 통해 전달될 메시지 구조체 */
    typedef struct {
        uint32_t fnd_number; // "TT:HH:BB" 형식
        char oled_mode_str[20];
        char oled_device_str[20];
    } display_data_t;
    
    /* 공유 데이터: 여러 태스크가 접근하는 시스템의 현재 상태 */
    typedef struct {
        system_mode_t current_mode;
        bool is_alarm_active; // 보안 경고 활성화 여부
    } system_status_t;
    ```
    
- 드라이버 레벨과 애플리케이션 레벨 사이에서 데이터/객체를 안전하게 관리

### 1.3. Hardware Abstraction Layer

- 애플리케이션 동작을 실제 드라이버 호출로 변환
- 하드웨어 세부 동작을 숨기고, 추상화된 API 제공
- 파일과 함수 이름 앞에 smarthome hal이라는 뜻의 접두사(`shh_`)가 붙음

| 파일명 | 주요 함수 | 역할 |
| --- | --- | --- |
| `shh_led.c` | `SHH_LEDs_Init()` | 모든 LED 초기화 (전원 LED만 켜고 나머지는 OFF 상태로 시작) |
|  | SHH_ModeLED_Set(system_mode_t mode) | 시스템 모드에 따라 LED 색상 설정 |
|  | SHH_SecurityStandbyLED_On() | 대기 상태 LED2 ON |
|  | SHH_SecurityStandbyLED_Off() | 대기 상태 LED2 OFF |
|  | SHH_SecurityWarningLED_On() | 보안 경고 LED(LED4, LED5, LED6) ON |
|  | SHH_SecurityWarningLED_Off() | 보안 경고 LED(LED4, LED5, LED6) OFF |
|  | `SHH_SecurityWarningLED_Toggle()` | 보안 경고 LED(LED4, LED5, LED6) 상태 토글(점멸 효과) |
|  | SHH_MainLight_SetBrightness(int8_t brightness_percent) | 메인 조명(LED8)의 PWM Duty Cycle 설정 → 밝기 제어 |
| `shh_actuator.c` | SHH_Fan_On() | DC 모터(팬) ON |
|  | SHH_Fan_Off() | DC 모터(팬) OFF |
|  | SHH_DoorLock_Open() | 서보 모터를 90도로 회전 → 도어락 열기 |
|  | SHH_DoorLock_Close() | 서보 모터를 0도로 회전 → 도어락 닫기 |
|  | SHH_Blinds_Move(int32_t steps) | 스텝 모터 시퀀스를 따라 지정된 스텝 수만큼 이동 → 블라인드 제어 |
|  | SHH_ExternalPower_On() | 릴레이 ON → 외부 기기 전원 공급 |
|  | SHH_ExternalPower_Off() | 릴레이 OFF → 외부 기기 전원 차단 |
| `shh_display.c` | SHH_FND_Init() | 모든 FND 자릿수 OFF (초기화) |
|  | SHH_FND_BufferUpdate(uint32_t number) | 온도·습도·밝기 데이터를 6자리 버퍼에 저장 |
|  | SHH_FND_Display() | 버퍼 값에 따라 한 자리씩 스캔 출력 (멀티플렉싱) |
|  | SHH_OLED_Init() | SSD1306 OLED 초기화 (디스플레이 On, 회전 설정 등) |
|  | SHH_OLED_Clear() | 화면 전체 클리어 (모든 픽셀 OFF) |
|  | SHH_OLED_SetCursor(uint8_t x, uint8_t y) | 커서 위치 설정 (열·페이지 기준) |
|  | SHH_OLED_PrintChar(char c) | 5x8 폰트 한 글자 출력 |
|  | SHH_OLED_PrintString_5x8(const char* str) | 문자열 출력 (문자 반복 호출) |
| `shh_sensor.c` | SHH_ReadTemperature() | DHT11로부터 온도 값 읽기 |
|  | SHH_ReadHumidity() | 마지막으로 읽은 습도 값 반환 |
|  | _SHH_Read_DHT11_40bit_Data(uint8_t* data) | DHT11 통신 프로토콜 수행 |
|  | `SHH_ReadBrightnessSensor()` | CDS 광센서 값을 ADC로 읽어 0–100% 밝기로 변환 |
|  | SHH_ReadManualControlVr() | VR 가변저항 값을 ADC로 읽어 0–100% 비율로 변환 |
|  | `SHH_uWave_StartMeasurement()` | 초음파 센서 Trig 핀에 10µs 펄스 출력 → Echo 측정 준비 |
|  | `SHH_uWave_GetDistanceCm()` | Echo 신호의 HIGH 지속시간을 바탕으로 거리(cm) 계산 (duration / 58) |
| `shh_sound.c` | `SHH_Buzzer_StartAlarm()` | 보안 알람용 부저 ON |
|  | `SHH_Buzzer_StopAlarm()` | 보안 알람용 부저 OFF |
|  | `SHH_Piezo_Beep()` | 버튼 입력 피드백용 피에조 비프음 짧게 출력 |
| `shh_system.c` | `SHH_Init()` | 스마트홈 시스템 전체 초기화 <BR>① 코어/클럭 초기화 <BR>② PORT 클럭 및 핀 기능(Mux) 설정 (UART, CAN, I2C, ADC, PWM, GPIO) <BR>③ GPIO 입력/출력 핀 초기화 (버튼, LED, 모터, 릴레이 등) <BR>④ 주변장치 드라이버 초기화 (ADC, FTM, I2C, CAN, LPIT, UART) <BR>⑤ PWM 채널 초기화 (메인 조명, 서보 모터) <BR>⑥ 인터럽트 소스 설정 (초음파 Echo, 버튼, 보안 LED 타이머 등) 및 NVIC 우선순위 등록 |
| `shh_uart.c` | `SHH_Uart_Printf(const char* format, ...)` | 포맷 문자열을 받아 UART1로 전송. 내부적으로 뮤텍스를 사용해 여러 태스크의 동시 접근 충돌을 방지 |

### 1.4. Task Layer (`sh_tasks.c`)

- 실제 RTOS Task의 동작을 구현
- 버튼 입력, 센서 데이터, CAN 명령, 보안 이벤트 처리 로직 포함
- 시스템 모드에 따라 제어 로직 수행
